# Signals and Systems

This book collects the lab material for the **Signals and Systems** course (2nd year of the Computer Engineering degree). The lab sessions use **MATLAB**, a tool designed for numerical and matrix computation that lets you define, plot and transform signals with very few lines of code.

## How to use this book

Each lab session has its own chapter. In each one you will find:

- **Learning objectives** at the start, so you know what you should master by the end.
- **Explanations and code examples** ready to copy into MATLAB and modify.
- **Exercise statements**, highlighted in boxes, in the same order as the session handout.
- **Proposed solutions**, collapsed: try to solve each exercise before expanding them.

```{admonition} If you already program in C
:class: tip

The first session is written for students who already know C. Many explanations compare the syntax of both languages directly so you can build on what you already know.
```
